# Getting support

## Questions

Read the [README](README.md), the
[user manual](https://sebastienrousseau.com/bankstatementparser-transport-ebics/) and the runnable
[`examples/`](examples/) first. Questions that remain go to
[GitHub Discussions](https://github.com/sebastienrousseau/bankstatementparser/discussions)
on the core repository, which the whole suite shares.

## Bugs and feature requests

Open an issue with the bug or feature template at
<https://github.com/sebastienrousseau/bankstatementparser-transport-ebics/issues/new/choose>.
For a bug, include your Python version, the package version
(`python -c "import bankstatementparser_transport_ebics; print(bankstatementparser_transport_ebics.__version__)"`), a minimal
reproducer with account data redacted, and the full traceback.

## Security

Do not open a public issue for a vulnerability; follow
[`SECURITY.md`](SECURITY.md).

## Supported versions

Fixes land on the latest `0.0.x` release. Python 3.10 or later is
required; [`docs/POLICIES.md`](docs/POLICIES.md) says when that floor
moves.
